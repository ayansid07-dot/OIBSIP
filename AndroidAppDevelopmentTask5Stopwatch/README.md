# Oasis Infobyte Internship - Task 5: Stopwatch App

This directory contains the source code for the Stopwatch Application, completed as Task 5 of the Android App Development internship at Oasis Infobyte.

### Tech Stack
* **Language:** Java
* **Layout:** XML
* **Environment:** Android Studio

### Key Features
* Accurate time tracking with millisecond precision (`00:00:000` format).
* **Start, Pause, and Reset** functionality for complete timer control.
* Clean and simple user interface with color-coded buttons.
* Real-time UI updates using Android's `Handler` and `SystemClock`.
