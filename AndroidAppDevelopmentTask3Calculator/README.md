# Oasis Infobyte Internship - Task 3: Calculator App

This directory contains the source code for the Calculator Application, completed as Task 3 of the Android App Development internship at Oasis Infobyte.

### Tech Stack
* **Language:** Java
* **Layout:** XML
* **Environment:** Android Studio

### Key Features
* Support for basic arithmetic operations (Addition, Subtraction, Multiplication, Division).
* Parentheses `( )` support for evaluating complex mathematical expressions.
* Dedicated Clear `C` button to reset the input display.
* Clean, responsive UI with custom-styled rounded buttons.
* Real-time expression evaluation and error handling for invalid inputs.
