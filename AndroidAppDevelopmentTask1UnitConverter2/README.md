# 📱 Unit Converter Application

## 📝 Description
This repository contains the source code for the Unit Converter app, developed as part of the Oasis Infobyte SIP Internship. This application allows users to seamlessly convert values between various units of measurement based on user input.

## 🚀 Tech Stack
* **Language:** Java
* **UI/Layout:** XML
* **Environment:** Android Studio

## ✨ Key Features
* Support for 3 measurement categories: Length, Weight, and Temperature.
* Dynamic category selector (Spinner) that automatically resets source and target unit dropdowns.
* Input validation with Toast messages for empty or non-numeric entries.
* Real-time calculation and result display with proper unit labels.
